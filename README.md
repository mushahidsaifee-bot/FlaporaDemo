# Altis Fitness Club

Website for **Altis Fitness Club**, located at ALIF TOWER, Betal Nagar, Kondhwa Budruk, Pune, Maharashtra 411048, India.

## Tech Stack
- **HTML5** (Semantic markup, Schema.org `ExerciseGym` JSON-LD, Open Graph metadata)
- **CSS3** (Custom properties, responsive grid, CSS transitions, `prefers-reduced-motion` support)
- **Vanilla JavaScript (ES6+)** (Zero frontend frameworks)

## Project Structure
- `index.html` — Complete landing page markup (Navigation, Hero, Statistics, About, Facilities & Equipment, Training Environment, Trainers, Gallery + Lightbox, Customer Reviews Carousel, FAQ Accordion, Contact & Location, Footer)
- `style.css` — Design system and responsive styles (`#101010` Charcoal, `#191919` Graphite, `#C6FF36` Electric Lime, `#FFFFFF` White)
- `script.js` — Interactive navigation, counters, parallax, gym media hydration, gallery lightbox, testimonial carousel, FAQ accordion, form validation, and scroll-to-top
- `assets/images/` — Converted PNG gym photographs (`unnamed.png` through `unnamed-7.png`) generated from the original `.webp` files in the root directory
